## Rhino.UI investigation

No separate Rhino.UI XML reference located in inspected exact installed distribution or matching official NuGet packages; cached public RhinoCommon web type dataset has no exact Rhino.UI.dll type matches. Official guides/examples provide selected UI usage, not a complete member reference. This is evidence of the inspected sources, not a claim that unpublished or unsearched McNeel material cannot exist.

The `Rhino.UI` namespace in RhinoCommon is not the separate `Rhino.UI.dll` assembly. Full target assembly metadata is retained even where semantic reference documentation is absent. 27 canonical guide/example records provide selected UI usage. Exact inspected package file lists, installed source paths, web comparison and guide record IDs: `reports/rhino_ui_documentation_audit.json`.

Authoritative discovery entry points: [RhinoCommon components](https://developer.rhino3d.com/guides/rhinocommon/what-is-rhinocommon/), [official NuGet guidance](https://developer.rhino3d.com/guides/rhinocommon/using-nuget/), [published UI namespace](https://developer.rhino3d.com/api/rhinocommon/rhino.ui?version=8.x). Matching RhinoCommon and RhinoWindows packages supply no Rhino.UI XML. Current web material remains discovery evidence, not a replacement for target-version XML.

Unmatched XML is classified against public and nonpublic binary metadata in `manifest/xml_unmatched.jsonl`; ten Eto package declarations are absent from selected installed metadata and are not invented as target APIs.
